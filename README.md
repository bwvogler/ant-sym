# jev-ants

An ant colony that forms whatever you type or upload, where every ant's step is decided by [Jev](https://typesafe.ai), TypeSafe's System One decision model. Hundreds of ants start scattered; each one looks at the ants around it and at how much ink its patch of paper still needs, asks Jev which way to step, and the picture emerges from the swarm.
